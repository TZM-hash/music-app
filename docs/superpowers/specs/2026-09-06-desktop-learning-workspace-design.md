# 电脑端音乐学习工作区整合设计

## 目标

围绕浙江省小学 1—6 年级课堂，把电脑端的“今日探索”“音乐探索馆”“互动课堂”和“作品/素材入口”恢复成连续、可探索的学习工作区。音乐欣赏、情绪、动作、故事、文化与乐理线索继续使用现有数据和保存逻辑，只调整信息架构与桌面端呈现。

## 已确认的范围

1. 今日探索不再拆成四个内部分页，现有主探索、今日探险、推荐路线、本次进度、今日任务和最近作品在同一个自然滚动页面中展示。
2. 音乐探索馆参考 `ccb4879`，左侧持续显示音乐方向、教材来源和线索卡，右侧显示当前线索卡的具体内容。保留右侧“知识学习 / 探索发现”局部切换和现有互动能力。
3. 互动课堂标题栏增加作品选择下拉菜单，切换后立即加载对应探索单元；底部不再提供“换一首作品”按钮。
4. 互动课堂左侧的 1—6 阶段导航改为可直接点击的页面切换。阶段按钮可以跳到任意阶段，但“下一步”仍遵循现有回答条件，探索记录与完成判定不被绕过。
5. 作品地图与素材库合并为一个“作品与素材”工作区，使用“作品地图 / 曲库与故事”局部切换。保留现有作品筛选、曲目试听、故事详情、测验、导入和进入探索等功能；旧 `library` 路由作为兼容入口打开合并工作区的素材视图。

## 电脑端布局

- 只增加或修改 `min-width: 1024px` 规则；移动端断点和移动导航不改。
- 今日探索、探索馆和合并工作区采用自然高度与纵向滚动，不用固定视口裁切内容。
- 探索馆桌面端采用左侧约 280—320px 的筛选/线索栏，右侧为可滚动的当前内容区。
- 互动课堂保留现有三栏：左阶段导航、中间互动内容、右侧发现摘要；数字阶段按钮在桌面端保持清晰的点击反馈。

## 数据与兼容性

- 不新增数据库、localStorage schema 或外部依赖。
- 继续使用 `EXPLORATION_UNITS`、`WORK_SUMMARIES`、`allSongs` 和百科数据。
- 不删除阶段一至四已有入口、探索会话、发现卡、作品和素材操作。
- 旧的 `library` 路由和已有 `navigate('library')` 调用继续有效。

## 验收标准

- Home、Theory 不再依赖页面级 `PagePager` 才能看到主要内容。
- 探索馆左侧筛选变更后，线索卡列表和右侧选中内容同步更新；无匹配时显示清晰空状态。
- 互动课堂标题栏存在作品下拉菜单，选择另一作品后标题、问题、阶段内容和会话按作品切换；页面底部没有“换一首作品”按钮。
- 互动课堂阶段 1—6 的按钮都可点击，点击任意数字会切换当前阶段并更新高亮；尚未完成的阶段不因此被判定完成。
- 作品地图和素材库在同一工作区内可切换，两个入口的核心功能均可用。
- `npm test`、`npm run lint`、`npm run build` 通过，构建后的 `dist/index.html` 与根目录 `乐动课堂.html` 内容一致。
