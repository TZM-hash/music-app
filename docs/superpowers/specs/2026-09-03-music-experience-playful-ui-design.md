# 音乐体验与童趣界面升级设计规格

## 目标与边界

将现有中小学音乐工具集合收拢为“音乐探索游乐园”。本次只覆盖学生端的体验串联、三种轻量互动、浙江主题适配、学生导航和视觉层；不新增排行榜、班级竞争、货币、复杂养成，也不改变已有音频引擎和本地数据格式。

## 用户体验原则

1. 先听后讲：首屏先给可播放的声音或节奏，不用长说明挡住入口。
2. 身体参与：每个任务至少有一次点击、拍击、跟随或拖动回应。
3. 没有唯一审美答案：表达题保存学生的感受，不把审美偏好换算成分数。
4. 小步完成：一个主题拆成 1—5 分钟的步骤，完成任一步都能获得正反馈。
5. 年级适配而非三套产品：用提示、时长、复杂度和内容映射适配 1—6 年级。
6. 离线优先：所有核心互动通过本地代码和已有合成音完成，单文件可运行。

## 交付面

- 体验定义与年级适配纯函数。
- 可复用互动舞台：声音侦探、节奏精灵、音乐画布。
- 首页和挑战中心的任务驱动入口。
- 四项学生主导航及移动底部导航。
- 童趣但不幼稚的全局视觉覆层和响应式规则。
- 单元测试、浏览器交互验证、构建与单文件校验。
