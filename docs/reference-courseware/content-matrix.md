## 来源与资源规则

- 上述矩阵中的人音版知识点统一使用 `renyin-reference`。
- 浙江教材已有内容继续使用现有 `textbook` 映射；不能因为复用同一活动而改变来源。
- `cataloged` 只代表内容已经登记，不代表页面功能已经完成；实现状态由执行计划中的阶段任务推进。
