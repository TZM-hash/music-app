# 浙江人音版教材探索体系

## Goal

把现有音乐探索空间调整为面向浙江省小学 1—6 年级、人民音乐出版社（人音版）小学音乐教材的“教材同步 + 地方拓展”体验：学生在一张探索卡里完成听、猜、玩、创作、表达，并留下可回看的“我的音乐发现”。

## Requirements

1. **教材范围**
   - 覆盖小学 1—6 年级，并区分上、下册。
   - 以浙江省常用人音版小学音乐的能力梯度和综合实践结构建立可校准的教材对照骨架。
   - 每张理论/探索主题都能显示年级、册次、对照主题和“教材同步 / 教材外拓展”来源。
   - 不复制教材整首歌曲、整页谱面或未经授权录音；内容使用能力目标、短提示和可替换的自制演示。

2. **学生画像**
   - 学生档案可保存年级和册次，兼容已有没有年级字段的旧数据。
   - 新增学生默认进入小学中段的安全起点，老师可以在名册中调整。

3. **探索推荐**
   - 首页继续保留唯一的“探索卡片”。
   - 推荐优先匹配当前学生年级/册次、未完成主题和近期薄弱方向；没有学生时提供小学通用推荐。
   - 推荐稳定可复现，同一天同一学生刷新页面不会跳来跳去。

4. **我的音乐发现**
   - 学生完成探索后可以保存一句简短发现，记录主题、教材对照、年级和时间。
   - 记录按学生隔离，支持最近记录摘要，并随课堂备份导出/导入。
   - 删除学生时级联删除其发现记录。

5. **浙江教材外拓展**
   - 提供少量可选的浙江声音入口（越剧、江南丝竹、采茶/水乡节奏、地方民歌等），每条都说明与教材能力点的联系。
   - 拓展内容复用现有探索馆/素材库/创作工具，不新增顶层导航和竞争排行。

6. **现有页面调整**
   - 音乐探索馆支持按年级筛选，并在主题详情展示教材对照信息。
   - 学段总览明确标注“浙江人音版小学音乐”，可切换 1—6 年级查看目标与主题数量。
   - 名册显示并编辑学生年级/册次。
   - 首页“本次进度”增加紧凑的最近发现摘要，不重新引入多 KPI 卡片。
   - 班级对战保持不可进入；现有探索卡片、训练、乐器和创作入口继续可用。

## Non-goals

- 不建立完整的教材电子书、曲谱仓库或受版权保护的音频分发系统。
- 不新增金币、排行榜、宠物、复杂徽章墙或另一套课程导航。
- 不移除已有初中主题；它们作为“教材外拓展”保留，但小学推荐优先使用核心主题。

## Acceptance Criteria

- [ ] `THEORY_TOPICS` 中的主题具有浙江人音版对照元数据，且小学主题覆盖 1—6 年级，初中主题标记为拓展。
- [ ] 推荐函数能依据学生年级/册次、已完成主题和薄弱类别稳定返回合适主题，并有无年级/空数据兜底。
- [ ] 学生名册可新增、修改并显示年级/册次，旧名册 JSON 仍可正常读取。
- [ ] “我的音乐发现”可保存、按学生读取、生成摘要、删除学生时级联清理，并纳入课堂备份。
- [ ] 音乐探索馆、学段总览、首页显示教材对照和浙江拓展入口，移动端无横向溢出。
- [ ] 新增逻辑先有失败测试，再实现；`npm test`、`npm run lint`、`npm run build` 全部通过。
- [ ] 最新构建产物覆盖根目录单文件 `乐动课堂.html`，并与 `dist/index.html` 内容一致。

## Assumptions

- “复合教材”按“综合音乐实践 / 综合性教材体验”理解，界面文案采用“浙江人音版小学音乐（综合实践）”。
- 由于不同印次和学校配套册次的单元名称可能有差异，默认提供“教材对照主题”骨架；未来可只改数据文件，不改组件逻辑即可校准具体目录。
