# 教学展示视口布局实施计划

> 本计划延续已批准的“音乐手作乐园”视觉系统，直接在当前 `master` 工作树执行；每个阶段完成后运行定向验证并独立提交。

## 阶段 1：展示视口基础

- 新增纯函数分页工具和可复用 `PagePager`，覆盖边界、键盘导航和可访问名称。
- 在应用壳层建立展示视口类，桌面/移动端默认隐藏外层滚动，保留明确的页面切换区域。
- 收紧侧边栏和顶栏高度，消除 1280×720 下导航自身滚动。

## 阶段 2：主要内容页分段

- 首页：保留探索卡片与本次进度，拆成“今日入口 / 进度与任务”两页。
- 玩乐：拆成“今日玩乐 / 更多练习”两页。
- 探索馆：拆成“选主题 / 听与看 / 玩与说”三页，并让主题列表分页。
- 我的、互动课堂、学段总览、教师成长观察和学生档案：通过紧凑分区或页签让主要内容在单一视口内可达。
- 素材库：歌曲和音乐故事列表分页，详情不再依赖内部纵向滚动。

## 阶段 3：工具页与验收

- 检查钢琴、打击乐、竖笛、木琴、混音器及五类小游戏的固定高度、画布和列表，保证单屏可操作。
- 验证 1280×720、390×844、键盘访问和 `prefers-reduced-motion`。
- 运行测试、lint、类型检查、构建，重新生成根目录单文件并比对 `dist/index.html`。
