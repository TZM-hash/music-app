# 乐动课堂 · Music Edu App

面向浙江省小学 1—6 年级的音乐探索互动空间，以人音版小学音乐教材的能力主线为核心，结合听、玩、创作、表达与少量浙江地方音乐拓展。纯前端单文件应用，可离线双击打开使用。

## 功能一览

- **乐器演奏**：钢琴（含采样音色与延音踏板）、架子鼓、木琴、竖笛指法
- **音乐游戏**：听音辨键、节奏复制、太鼓节奏、视唱练耳、看谱演奏
- **教材探索**：按年级、上下册和来源筛选浙江人音版对照主题，首页按学生档案稳定推荐探索卡
- **乐理学习**：互动乐理课程、知识闯关、智能复习、音乐百科
- **创作工具**：混音器（多轨步进音序）、自定义曲库
- **浙江拓展**：越剧、江南丝竹、水乡声音、采茶与龙舟节奏等轻量探索入口
- **课堂管理**：学生年级/册次档案、按学生隔离的练习进度、音乐发现和数据看板
- **数据备份**：一键导出/导入全部课堂数据（含“我的音乐发现”）

## 快速开始

```bash
npm install     # 安装依赖
npm run dev     # 启动开发服务器（http://localhost:5173）
npm run build   # 类型检查 + 构建单文件 HTML 到 dist/
npm run preview # 预览构建产物
npm test        # 运行单元测试（node:test）
```

构建产物为单个 HTML 文件（`vite-plugin-singlefile`）。发布时将 `dist/index.html` 同步为根目录的 `乐动课堂.html`，即可直接双击打开，无需服务器。

## 技术栈

- React 18 + TypeScript + Vite
- Tone.js（Web Audio 合成与精确节拍调度）
- 原生 Web Audio API（麦克风音高检测，自相关算法）
- 数据全部存于浏览器 localStorage，无后端

## 项目结构

```
src/
  components/   通用组件（侧边栏、顶栏、五线谱、庆祝动画等）
  pages/        各功能页面（乐器、游戏、乐理、课堂管理）
  music/        音频引擎、曲目库、乐理数据、音高检测
  state/        状态管理（导航、进度、学生、备份）
tests/          纯逻辑单元测试（node --test）
docs/           设计文档与开发计划
```

## 注意事项

- **教材对照**：当前单元名称是可校准的能力主题骨架，不包含教材整曲、整页谱面或原版录音；如学校使用的印次目录不同，可集中调整 `src/music/zhejiangCurriculum.ts`。
- **钢琴采样音色**：采样已内置在单文件中，离线打开也可使用；浏览器音频策略仍要求首次播放由用户点击触发。
- **麦克风功能**：视唱/音高检测类游戏需要浏览器授权麦克风权限。
- **数据安全**：课堂数据存在浏览器本地，换电脑或清缓存会丢失，请定期使用「数据备份」功能导出。
