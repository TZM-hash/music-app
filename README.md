# 乐动课堂 · Music Edu App

面向中小学的音乐探索互动空间：听、玩、创作与闯关。纯前端单文件应用，可离线双击打开使用。

## 功能一览

- **乐器演奏**：钢琴（含采样音色与延音踏板）、架子鼓、木琴、竖笛指法
- **音乐游戏**：听音辨键、节奏复制、太鼓节奏、视唱练耳、看谱演奏
- **乐理学习**：互动乐理课程、知识闯关、智能复习、音乐百科
- **创作工具**：混音器（多轨步进音序）、自定义曲库
- **课堂管理**：学生名册、按学生隔离的练习进度、团队对战、数据看板
- **数据备份**：一键导出/导入全部课堂数据（JSON）

## 快速开始

```bash
npm install     # 安装依赖
npm run dev     # 启动开发服务器（http://localhost:5173）
npm run build   # 类型检查 + 构建单文件 HTML 到 dist/
npm run preview # 预览构建产物
npm test        # 运行单元测试（node:test）
```

构建产物为单个 HTML 文件（`vite-plugin-singlefile`），可直接双击用浏览器打开，无需服务器。

## 技术栈

- React 18 + TypeScript + Vite
- Tone.js（Web Audio 合成与精确节拍调度）
- 原生 Web Audio API（麦克风音高检测，自相关算法）
- 数据全部存于浏览器 localStorage，无后端

## 项目结构

```
src/
  components/   通用组件（侧边栏、顶栏、五线谱、庆祝动画等）
  pages/        各功能页面（乐器、游戏、乐理、课堂管理）
  music/        音频引擎、曲目库、乐理数据、音高检测
  state/        状态管理（导航、进度、学生、备份）
tests/          纯逻辑单元测试（node --test）
docs/           设计文档与开发计划
```

## 注意事项

- **钢琴采样音色**：首次进入钢琴页时会从 Tone.js 官方 CDN 加载 Salamander Grand 采样，需要联网；离线或加载超时（8 秒）会自动降级为内置合成音色，不影响使用。
- **麦克风功能**：视唱/音高检测类游戏需要浏览器授权麦克风权限。
- **数据安全**：课堂数据存在浏览器本地，换电脑或清缓存会丢失，请定期使用「数据备份」功能导出。
